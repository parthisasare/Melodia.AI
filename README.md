# 🎶 Melodia.AI

Melodia.AI is a generative voice and dialog system that bridges **speech-to-text** and **text-to-speech** with advanced cloning and dubbing capabilities.  
Built using **ElevenLabs**, **OpenAI APIs**, **LangChain**, and modern **Python libraries** with **FastAPI**, it enables natural, emotionally resonant human-computer interaction.

---

## ✨ Features
- 🎤 **Voice Recording → Text**: Record your voice and convert it into accurate transcripts.
- 📝 **Text → Voice**: Generate lifelike speech from text using voice cloning and dubbing.
- 🔗 **LangChain Integration**: Orchestrates LLM workflows for contextual and adaptive responses.
- ⚡ **FastAPI Backend**: Lightweight, high-performance API server for real-time interaction.
- 🔑 **Secure API Keys**: Uses OpenAI and ElevenLabs APIs for advanced speech and language capabilities.

---

## 🛠️ Tech Stack
- **Programming Language**: Python  
- **Framework**: FastAPI  
- **AI/ML Libraries**: LangChain, OpenAI SDK  
- **Voice Tech**: ElevenLabs API  
- **Other Tools**: pydub, numpy, requests, uvicorn

## 🚀 Getting Started

### Prerequisites
- Python 3.9+  
- Valid **OpenAI API key**  
- Valid **ElevenLabs API key**

```bash

cd melodia.ai

# Create virtual environment
